# Medicus Hospital — WebPage

A modern and responsive healthcare website developed as a frontend project, designed to provide users with an intuitive experience for exploring medical services, doctors, and appointment options.

##  Features

* Modern and responsive homepage
* Doctors directory with search, filtering, and sorting
* Medical services with dedicated detail pages
* Appointment booking form with validation
* Patient reviews and ratings
* Google Maps integration
* Fully responsive design for desktop, tablet, and mobile
* Modern UI with custom animations and transitions
* Cross-browser compatibility
* Dynamic content generated with JavaScript
* Reusable and modular JavaScript structure

## Technologies

* **HTML5** — Semantic page structure
* **CSS3** — Custom styling, responsive layouts, animations, and transitions
* **JavaScript (ES6+)** — Dynamic content and interactive functionality
* **Bootstrap 5** — Responsive grid system and UI components
* **Git / GitHub** — Version control and project management
* **Leaflet.js** — Interactive maps

## Main Pages

### Home

Introduces the hospital, its mission, statistics, medical services, doctors, patient reviews, and contact information.

### Services

Displays available medical services with filtering/navigation and dedicated service detail pages.

### Doctors

Provides a searchable and filterable list of doctors, including their specialties and professional information.

### Appointments

Allows users to select a department and doctor and submit an appointment request through a validated form.

### Reviews

Displays patient reviews with interactive star ratings and a dynamic review interface.

### Contact

Includes contact information, appointment-related functionality, and an interactive map.

## Responsive Design

The website was developed with a mobile-first approach and optimized for:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

The layout, navigation, cards, forms, typography, and footer adapt to different screen sizes.
